# Medical Clinic — Patient App

> Interactive web prototype for specialised medical and healthcare clinics, with appointment overview and specialty search.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Healthcare & specialised clinics

Interactive web prototype for specialised medical and healthcare clinics, with appointment overview and specialty search.

**Highlights**

- Search by doctor, exam or specialty
- Upcoming appointment card and digital insurance card
- Accepted insurance plans and opening hours

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
